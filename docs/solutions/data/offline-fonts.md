# Проверка офлайн-шрифтов

## Context
Захваченная страница должна сохранять шрифты при офлайн-рендере.

## Symptoms
Повреждённый WOFF2 давал accepted baseline с подставленным шрифтом.

## What did not work
`document.fonts.ready` завершался при ошибке загрузки. Запрет любого `FontFace.status === 'error'` также отклонял отсутствующие запасные `local()`-шрифты корректной страницы.

## Root cause
Готовность font set не подтверждает декодирование ресурса. Локальные запасные шрифты и загруженные файлы требуют разных проверок.

## Solution
Проверять байты запрошенных WOFF2 через `FontFace.load()`, не добавляя проверочный face в документ.

## Why it works
Проверяется декодирование файла без изменения оформления страницы и её цепочки локальных шрифтов.

## Verification
Повреждённый WOFF2 отклоняется. Отсутствующий необязательный `local()`-шрифт не отклоняет baseline. Обе регрессии воспроизведены до исправления.

## Prevention
При изменении маршрутизации ресурсов запускать оба font-теста.

## Applies when
Офлайн-сцены с проверенными по SHA-256 файлами WOFF2.
