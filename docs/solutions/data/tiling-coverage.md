# Полное покрытие дефектов при tiling

## Context
Начальный профиль — tiles 1024 px с overlap 128 px.

## Symptoms
Часть размеченных строк шире tile; другие bbox пересекают его границы.

## What did not work
Увеличение overlap не помещает bbox шириной более 1024 px в такой tile.

## Root cause
Экспорт требует полного покрытия каждого issue и исключает частично размеченные tiles.

## Solution
Явная опция `--tile-uncovered original` сохраняет непокрываемый случай одним исходным кадром со всеми bbox. Manifest содержит `kind: original`, отчёт — отдельный счётчик. По умолчанию сохраняется ошибка покрытия.

## Why it works
Разметка и пиксели не теряются; фрагменты дефектов не превращаются в negatives.

## Verification
Проверены исходные пиксели, bbox, счётчики, пробелы покрытия и лимит числа tiles. На срезе из 6068 случаев все issues покрыты; 76 случаев требуют оригинала.

## Prevention
Проверять покрытие до записи обучающих файлов. Считать оригиналы отдельно от tiles.

## Applies when
Дефект или сочетание дефектов не помещается в заданную сетку tiles.
