# Разделение конечного каталога

## Context
Двадцать семейств собственных страниц.

## Symptoms
Первоначальное хеширование дало 19 train, 1 val и 0 test.

## What did not work
Порог 90/5/5 для каждой группы не гарантирует непустые выборки.

## Root cause
Малое число независимых групп.

## Solution
План `lumen-grammar-v2` заморожен до генерации: 18 семейств train, chat — val, calendar — test. Назначения получены ранжированием SHA-256 имён групп.

## Why it works
Семейства не делятся между выборками. 90/5/5 относится к группам, а не к изображениям.

## Verification
Контракт фиксирует все 20 назначений. После генерации отдельно проверяется наличие accepted cases в каждой выборке.

## Prevention
Не менять план v2 при расширении каталога. Не объединять старые smoke с новым корпусом.

## Applies when
Известен конечный каталог шаблонов. Внешние источники без подтверждённой lineage остаются целыми source-группами.
