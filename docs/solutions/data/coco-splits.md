# Разделение в COCO-экспорте

## Context
Корпус разделён по группам исходных сцен.

## Symptoms
Standalone COCO не содержал назначения train/val/test.

## What did not work
Общий `annotations.json` сохранял изображения и bbox, но терял разделение.

## Root cause
Экспорт не переносил `split` из case record.

## Solution
Общий файл сохранён. Добавлены отдельные COCO-файлы по split; изображения общие. Записи изображений содержат `split` и `split_group`.

## Why it works
Назначения переносятся без повторного случайного разделения. Изображения и аннотации фильтруются одинаково.

## Verification
Регрессия проверяет три назначения, пустые выборки и соответствие bbox изображениям в смешанном корпусе.

## Prevention
Проверять сохранение split при добавлении форматов экспорта.

## Applies when
Производные изображения одной сцены должны оставаться в одной выборке.
