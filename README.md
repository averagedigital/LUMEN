# LUMEN

Генератор синтетических UI-дефектов и пар скриншотов для анализа изменений интерфейса.

- INSPECT: изображение и координаты дефектов.
- DIFF: изображения до и после изменения, разметка и маска изменённых пикселей.
- Экспорт: YOLO, COCO, JSONL для Hugging Face Datasets.
- Дополнительные аннотации: элементы, состояния и взаимодействия.

TypeScript, Playwright, Python, OpenCV, SQLite.

```sh
docker build -t lumen-data .
docker run --rm lumen-data lumen-data --help
```

Команды CLI: `sources`, `generate`, `qa`, `review`, `export`, `reproduce`.

В конфигурации генерации `operators` задаёт список операторов; повторения задают веса.
Список и его порядок фиксируются для `resume`. Без списка используется встроенный каталог.
Механизм мутации хранится отдельно от симптомов, подтверждённых browser-валидатором.

`benign_near_boundary` сохраняет последнее допустимое состояние перед подтверждённой
поломкой; `benign_composite_control` — безопасный компонент составного сценария.
Рецепт содержит `control_of` и, для составного сценария, `control_component` (0 или 1).
Составные сценарии принимаются только при корректности обоих компонентов по отдельности.

`corpus` разделяет `lumen-synth` и `lumen-modern`; `defect_origin` описывает происхождение
мутации независимо от лицензии исходной страницы. Старые источники без классификации
учитываются как `unclassified`.
